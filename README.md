# EUFÍA — Web institucional

Sitio estático en español, adaptable a móvil, basado en la identidad visual 01 de EUFÍA.

## Publicación

GitHub Pages: publicar la rama `main`, carpeta `/ (root)`. No requiere compilación. Todos los enlaces de archivos son relativos y funcionan bajo una URL de proyecto.

## Contenido y contacto

Los textos se editan en `index.html`. La paleta y estilos están en `style.css`. Los logotipos SVG se encuentran en `assets/`.

El formulario prepara una consulta para WhatsApp al número +55 88 99624-8510 indicado por el titular. El visitante revisa y envía el mensaje desde WhatsApp. No se almacena información en la web.

La tipografía utiliza Google Fonts (DM Sans y Playfair Display) con alternativas locales. El lettering de marca es una recreación vectorial del concepto aprobado. No se incluyen clientes, métricas o testimonios inventados.

## Revisión local

Ejecutar `node preview.cjs` y abrir la dirección indicada. El servidor de revisión no es necesario en GitHub Pages.
